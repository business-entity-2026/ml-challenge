# Dataset placement

Place the challenge-provided TSV files here locally. Dataset files are intentionally ignored by Git.

```text
data/
├── train/
│   ├── train_source1.tsv
│   ├── train_source2.tsv
│   ├── train_source3.tsv
│   └── train_ground_truth.tsv
└── test/
    ├── test_source1.tsv
    ├── test_source2.tsv
    └── test_source3.tsv
```

Use the exact challenge filenames. Do not add external data, APIs, geocoding results, or internet-based enrichment.
